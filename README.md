# Toontown (port a JavaScript)

Desde la pantalla de inicio hasta Minnie's Melodyland: Pick-A-Toon, Make-A-Toon, Toon-torial, Toontown Central, Daisy Gardens y
Minnie's Melodyland, con sus calles, Cogs, edificios, ToonTasks y los distritos en línea (batallas en grupo).

- **Jugar en internet:** abre el enlace de GitHub Pages de este repositorio.
- **Jugar con el archivo:** descarga `index.html` y ábrelo con Chrome, Edge o Firefox. La primera vez pide el enlace de GitHub Pages
  (de ahí baja los archivos `.pak`, que son los pesados).

Archivos: `index.html` (el cargador, 5 KB) y los paquetes `core.pak` (páginas, menú y sonidos), `ttc.pak` (Toontown Central,
ToonTasks y edificios por dentro), `cogs.pak` (Cogs y sus edificios), `tt.pak`, `dg.pak` y `mm.pak` (calles y patios de cada barrio).
Los paquetes se bajan recién cuando hacen falta.
